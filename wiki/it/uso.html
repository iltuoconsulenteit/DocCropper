Uso di DocCropper

L'interfaccia ora utilizza uno stile Material design con pulsanti più uniformi.

Home Uso
  1. Seleziona Carica file per scegliere le immagini oppure trascinale sulla pagina. Fino a dieci file alla volta sono accettati (limite configurabile). Da mobile puoi passare alla Fotocamera e acquisire più foto.
  2. (Pro) Puoi anche importare file PDF e aggiungere ogni pagina alla galleria.
  3. Regola i quattro angoli oppure fai doppio clic per rilevare automaticamente i bordi.
  4. Usa i cursori di luminosità e contrasto. (Pro) Converti le immagini in scala di grigi o B/N, elimina le pagine bianche e rimuovi lo sfondo. Puoi ripristinare i colori con il pulsante Colore e regolare la soglia di rimozione.
  5. Capovolgi o ruota le immagini se l'orientamento è errato.
  6. Aggiungi una filigrana di testo o immagine con dimensione, colore, font e angolo personalizzabili. Puoi applicarla a tutte le pagine.
  7. Premi Elabora immagine per ritagliare le foto.
  8. (Pro) Trascina le miniature per riordinarle.
  9. Premi il pulsante a forma di pennino sotto una pagina per caricare o disegnare la firma e poi Salva. La versione Free mantiene il watermark.
  10. Clicca Crea PDF. Scegli il livello di compressione (Basso, Medio o Estremo con qualità JPEG personalizzabile) e, se necessario, seleziona una versione PDF/A per archiviazioni legali. L'anteprima del layout si aggiorna mentre modifichi le opzioni. (Pro) Usa Firma remota per applicare una firma digitale e condividi via WhatsApp Web o Email.
