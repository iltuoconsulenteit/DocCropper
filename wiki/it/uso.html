Uso di DocCropper

L'interfaccia ora utilizza uno stile Material design con pulsanti più uniformi.

Home Uso
  1. Seleziona Carica file per scegliere le immagini oppure trascinale sulla pagina. Da mobile puoi passare alla Fotocamera e acquisire più foto.
  2. (Pro) Puoi anche importare file PDF e aggiungere ogni pagina alla galleria.
  3. Regola i quattro angoli oppure fai doppio clic per rilevare automaticamente i bordi.
  4. Usa i cursori di luminosità e contrasto. (Pro) Converti le immagini in scala di grigi o B/N ed elimina le pagine bianche. Puoi ripristinare i colori con il pulsante Colore.
  5. Premi Elabora immagine per ritagliare le foto.
  6. (Pro) Trascina le miniature per riordinarle.
  7. Scegli Firma sotto una pagina per caricare o disegnare la tua firma e premi Salva. La versione Free mantiene il watermark.
  8. Clicca Crea PDF. Usa Anteprima layout per visualizzare la disposizione. (Pro) Usa Firma remota per applicare una firma digitale e condividi via WhatsApp Web o Email.
