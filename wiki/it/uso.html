Uso di DocCropper

L'interfaccia ora utilizza uno stile Material design con pulsanti più uniformi.

L'intestazione può mostrare un banner rotante di immagini elencate in banner_images dentro settings.json. Inserisci i file in static/slide/ e usa il segnaposto {{lang}} nel nome per caricare la versione nella lingua corretta.

Un banner sponsor dedicato appare quando si imposta sponsor_banner e i loghi di cliente e sponsor diventano link tramite client_url e sponsor_url. In alternativa, un URL sponsor_frame può incorporare un riquadro promozionale in homepage.

Di default il riquadro mostra l'ultimo post di iltuoconsulenteit; le licenze sponsorizzate scontate richiedono quindi una connessione a Internet per visualizzarlo.

Il menu Sponsor apre una pagina integrata che mostra i livelli di sponsorizzazione caricati da Fabrik come riquadri Bronze, Silver e Gold, insieme a una tabella di esempio dei vantaggi per ciascun livello.

Il menu Aggiornamenti legge le voci da UPDATES.md e mostra l'ultima modifica anche in homepage quando non sono caricati documenti.

Una campanellina nell'intestazione verifica all'avvio e a intervalli regolari la presenza di nuove versioni. Cliccala e inserisci il PIN di aggiornamento per eseguire l'upgrade o ripristinare la versione precedente.

L'accesso tramite Google è disponibile solo quando license_check è attivo nelle impostazioni; altrimenti il modulo di login rimane disabilitato.

Home Uso
  1. Seleziona Carica file per scegliere le immagini oppure trascinale sulla pagina. Fino a dieci file alla volta sono accettati (limite configurabile). Su dispositivi mobili, dopo ogni acquisizione l'app torna alla galleria; tocca Aggiungi/Importa per aggiungere un'altra foto.
  2. (Pro) Puoi anche importare file PDF e aggiungere ogni pagina alla galleria.
  3. Regola i quattro angoli oppure fai doppio clic per rilevare automaticamente i bordi.
  4. Usa i cursori di luminosità e contrasto. (Pro) Converti le immagini in scala di grigi o B/N, elimina le pagine bianche e rimuovi lo sfondo. Puoi ripristinare i colori con il pulsante Colore e regolare la soglia di rimozione.
  5. Capovolgi o ruota le immagini se l'orientamento è errato.
  6. Aggiungi una filigrana di testo o immagine con dimensione, colore, font e angolo personalizzabili. Puoi applicarla a tutte le pagine.
  7. Premi Elabora immagine per ritagliare le foto.
  8. (Pro) Trascina le miniature per riordinarle.
  9. Premi il pulsante a forma di pennino sotto una pagina per caricare o disegnare la firma e poi Salva. La versione Free mantiene il watermark.
  10. Clicca Crea PDF. Scegli il livello di compressione (Basso, Medio o Estremo con qualità JPEG personalizzabile) e, se necessario, seleziona una versione PDF/A per archiviazioni legali. L'anteprima del layout si aggiorna mentre modifichi le opzioni. (Pro) Usa Firma remota per applicare una firma digitale e condividi via WhatsApp Web o Email.
