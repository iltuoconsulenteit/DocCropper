Guida a DocCropper

Home Uso

DocCropper permette di acquisire o caricare immagini di documenti, correggerne la prospettiva ed esportarle in un unico file PDF.

Funzionalità principali

  • Caricamento multiplo di immagini con drag & drop
  • Acquisizione da fotocamera o scelta file sui dispositivi mobili
  • Importazione delle pagine PDF direttamente in galleria (Pro)
  • Rilevamento automatico dei bordi con doppio clic
  • Ritaglio interattivo con correzione prospettica
  • Regolazione di luminosità e contrasto
  • Conversione in scala di grigi o bianco/nero (Pro)
  • Eliminazione delle pagine bianche all'import PDF (Pro)
  • Riordina le pagine trascinando le anteprime (Pro)
  • Aggiungi una firma disegnata o immagine prima dell'esportazione (Free con watermark)
  • Firma dal telefono tramite QR code (Pro)
  • Esporta PDF e condividilo via WhatsApp Web o Email (Pro)

Consulta la sezione Uso per una guida passo passo.

Le funzionalità contrassegnate con "(Pro)" richiedono una licenza Pro o Full. La versione Free consente firme base con watermark e massimo cinque immagini.
